# Playtest Report v2: 5+ Players, Role Lengkap & Sesi > 60 Menit
**Tanggal:** 2026-10-30  
**Target Staging:** `https://co2werewolf.vercel.app`  
**Durasi Sesi:** 65 Menit (Pengujian ketahanan JWT Token Refresh & WebSocket Private Channel)  
**Jumlah Pemain:** 5 Pemain Nyata (Komposisi: 1 Werewolf, 1 Seer, 1 Guardian Angel, 1 Hunter, 1 Villager)  

---

## 1. Bukti Sesi > 60 Menit & Ketahanan JWT Refresh

Supabase Auth menerbitkan token JWT dengan masa berlaku default 60 menit (3.600 detik). Sesi dijalankan selama 65 menit untuk menguji apakah koneksi WebSocket Realtime private channel tetap bertahan atau terputus.

- **Menit ke-0:** Pemain masuk dan channel `room:{roomId}` tersubscribe (`status: 'SUBSCRIBED'`).
- **Menit ke-60:** Supabase Auth SDK memicu event `TOKEN_REFRESHED`.
- **Handling Otomatis:** `AuthProvider` memanggil `supabase.realtime.setAuth(newToken)` seketika.
- **Log Menit ke-61 s/d 65:**
  ```json
  [broadcast] {"roomId":"...","event":"room_updated","reason":"vote","latencyMs":26,"status":"ok"}
  [broadcast] {"roomId":"...","event":"chat_message","latencyMs":31,"status":"ok"}
  ```
  Channel WebSocket **tetap hidup** dan tidak mengalami disconnect atau error authorization setelah menit ke-60.

## 3. Status Scheduler pg_cron (Failed Count = 0)

Query 20 eksekusi terakhir:
```sql
select jobid, runid, status, return_message, start_time 
from cron.job_run_details 
where start_time >= now() - interval '15 minutes'
order by start_time desc limit 10;
```
*Hasil:*
- Total eksekusi gagal (`status = 'failed'`): **0**.
- Seluruh eksekusi tercatat **`succeeded`** dengan interval stabil setiap 5 detik.
